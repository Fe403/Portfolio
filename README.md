🎯 Objetivo

Este portfólio foi criado para apresentar minha evolução como estudante de Ciência da Computação e desenvolvedor Full Stack em formação.

Acredito que aprender é um processo contínuo. Cada projeto representa um novo desafio, uma nova oportunidade de melhorar e escrever um código melhor do que o de ontem.

💡 Curiosidade

Nem sempre meu objetivo foi trabalhar com tecnologia. Antes, sonhava em seguir carreira na área policial. Com o tempo, descobri que o que realmente me motivava era entender como as coisas funcionam e encontrar maneiras de torná-las melhores.

Foi assim que a curiosidade por hardware evoluiu para a programação.

E sigo construindo essa jornada... uma linha de código por vez.

"Ainda não construí uma armadura igual à do Tony Stark... mas estou trabalhando em algo quase tão interessante." ⚙️
